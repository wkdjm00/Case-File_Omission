## 실행 방법

1. Unity에서 `Assets/01_Scenes/P0_Playtest.unity`를 연다. (씬이 없거나 다시 만들려면 메뉴 **Case File > P0 테스트 씬 만들기**)

3. 같은 시드는 같은 의뢰를 만든다(고정 테스트 사건 역할). 의뢰는 기존 생성 파이프라인이 만든 것이며, 손으로 쓴 fixture가 아니다.
